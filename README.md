# VocabRunner 3.21

A powerful vocabulary learning app with offline support and cloud sync.

View your app in AI Studio: https://ai.studio/apps/a8637214-5338-49ff-835c-3c668a1e19a7

---

## （1）功能描述文档 (Functional Description)

**核心定位：** 具备云端同步能力的离线优先（Offline-First）高效单词背诵工具。

### 1. 核心架构
*   **离线优先存储：** 采用 IndexedDB (Dexie.js) 作为本地主数据库，确保在无网络环境下依然能流畅进行学习、测试和数据管理。
*   **自动云端同步：** 内置存储抽象层，自动检测网络状态。在线时，操作会同步至服务器；离线时，操作保存在本地，待恢复连接后自动尝试同步。
*   **PWA 支持：** 符合渐进式 Web 应用标准，支持 Service Worker 资源缓存和 Manifest 配置，可安装至桌面或手机主屏幕，支持离线启动。
*   **跨实例同步：** 支持从其他 VocabRunner 服务器实例直接同步（下载）所有单词本数据。

### 2. 学习与测试系统
*   **多单词本管理：** 支持创建、切换和删除多个独立的单词本。
*   **沉浸式学习模式：** 采用卡片式设计，支持自动语音朗读（TTS）、音标显示及例句展示。
*   **智能测试模式：** 拼写检查机制，根据测试表现自动追踪单词掌握程度（需连续答对两次标记为“已掌握”）。
*   **进度追踪：** 实时统计每个单词本的“已学”和“掌握”进度。

### 3. 数据交互
*   **灵活导入：** 支持标准 CSV 和 Excel (.xlsx) 文件批量导入单词。
*   **示例引导：** 首次使用自动生成示例单词本，帮助用户快速上手。
*   **全局重置：** 提供一键重置功能，可清空所有本地及云端数据。

## （2）用户使用文档 (User Guide)

欢迎使用 **VocabRunner**！本手册将引导您快速掌握这款高效的背诵神器。

### 1. 快速开始
*   **访问应用：** 打开应用后，您会看到默认的“示例单词本”。
*   **安装到设备：** 
    *   **iPhone/iPad:** 点击 Safari 的“分享”图标 -> 选择“添加到主屏幕”。
    *   **电脑端:** 点击浏览器地址栏右侧的“安装”图标。
    *   *安装后，您可以像使用原生 App 一样在离线状态下打开它。*

### 2. 管理单词本
*   **切换单词本：** 点击首页顶部的单词本名称，在下拉菜单中选择您想学习的本子。
*   **导入新词：** 点击首页右上角的“+”号，选择您的 CSV 或 Excel 文件。
    *   *文件格式要求：包含 word, phonetic, meaning, sentence 四列。*
*   **删除单词本：** 在单词本下拉菜单中，点击对应本子旁的“垃圾桶”图标。

### 3. 学习与复习
*   **开始学习：** 点击“开始学习”，系统会为您挑选未学习的单词。点击卡片可查看释义和例句，点击喇叭图标可听发音。
*   **自我测试：** 点击“开始测试”，输入单词的正确拼写。
    *   **掌握标准：** 只有当您连续两次拼写正确，该单词才会被标记为“已掌握”。
    *   **提示：** 如果拼写错误，系统会自动显示音标并播放读音作为提示。

### 4. 离线使用说明
*   **无需担心网络：** 您可以在地铁、飞机等无网络环境下放心使用。所有的学习进度都会即时保存在您的手机/电脑本地。
*   **数据同步：** 当您重新连接网络并刷新应用时，本地的进度会自动尝试与云端同步，确保多端数据一致。

### 5. 设置与重置
*   **测试偏好：** 在“设置”中，您可以开启或关闭“测试时始终显示音标”。
*   **清空数据：** 如果您想重新开始，可以在设置中选择“重置所有数据”。*注意：此操作不可逆，将同时清空本地和服务器上的所有记录。*

### 6. 数据同步与迁移 (Data Sync & Migration)
*   **从其他服务器同步：** 
    1. 进入“设置”页面。
    2. 在“从服务器同步已有数据”部分，输入源服务器的 IP 地址。
    3. 点击“下载数据”。应用将从该服务器获取所有单词本并保存到当前设备及服务器。
*   **备份与迁移指南：**
    *   **迁移数据：** 当您更换服务器或设备时，只需在新实例的设置中输入旧服务器的 IP 并点击“下载数据”，即可完成所有单词本和进度的迁移。
    *   **手动备份：** 服务器上的数据存储在根目录的 `books/` 文件夹中。您可以定期备份该文件夹中的 `.json` 文件。
    *   **多实例同步：** 您可以通过此功能在多个 VocabRunner 实例之间保持数据同步，只需定期从主服务器“下载数据”即可。

## （3）本地局域网部署与 HTTPS 配置 (Local LAN & HTTPS)

为了在局域网（LAN）环境下让手机正常使用 PWA 的离线功能，必须配置 HTTPS。

### 1. 为什么需要 HTTPS？
浏览器（尤其是 iOS Safari）出于安全考虑，**强制要求** Service Worker 必须在安全源（HTTPS 或 localhost）下运行。在局域网通过 IP 访问时，如果不开启 HTTPS，离线模式将无法工作。

### 2. 证书部署步骤 (使用 mkcert)
本应用已内置双服务器支持：HTTP (3000端口) 和 HTTPS (3443端口)。

1.  **安装 mkcert**：在您的服务器电脑上安装 [mkcert](https://github.com/FiloSottile/mkcert)。
2.  **初始化根证书**：
    在终端运行 `mkcert -install`。这会生成本地根 CA 并将其安装到您电脑的系统信任库中。
3.  **找到根证书文件**：
    运行 `mkcert -CAROOT`。该命令会输出根证书所在的目录路径。在该目录下找到 `rootCA.pem` 文件，这是您需要发送到手机端安装的文件。
4.  **生成站点证书**：
    ```bash
    # 假设您的局域网 IP 是 192.168.1.100
    mkcert 192.168.1.100 localhost 127.0.0.1
    ```
3.  **放置证书**：
    *   将生成的 `.pem` 文件重命名为 `key.pem` 和 `cert.pem`。
    *   将这两个文件移动到 VocabRunner 项目的**根目录**（与 `package.json` 同级）。
4.  **重启应用**：
    运行 `npm run dev`。应用会自动检测到证书并启动 HTTPS 服务器。
    *   控制台应显示：`HTTPS Server running on https://0.0.0.0:3443`

### 3. 手机端配置（关键）
1.  **安装根证书**：将 `mkcert` 生成的 `rootCA.pem` 发送到手机并安装。
    *   **iOS**: 设置 -> 已下载描述文件 -> 安装。然后前往：设置 -> 通用 -> 关于本机 -> 证书信任设置 -> 开启对 mkcert 根证书的**完全信任**。
    *   **Android**: 设置 -> 安全 -> 更多安全设置 -> 加密与凭据 -> 安装证书 -> CA 证书。选择 `rootCA.pem` 并确认安装（不同品牌手机路径可能略有不同，建议直接在设置中搜索“CA 证书”）。
2.  **访问应用**：使用 HTTPS 端口访问，例如 `https://192.168.1.100:3443`。
3.  **安装 PWA**：
    *   **iOS**: 点击 Safari 分享按钮 -> “添加到主屏幕”。
    *   **Android**: 点击 Chrome 菜单 -> “安装应用”。

### 4. 离线工作排查
如果离线仍不工作，请检查：
*   是否使用了 HTTPS 访问？（HTTP 无法离线）
*   是否在 iOS 上开启了“完全信任”根证书？
*   是否在有网时完整打开过一次应用（让 Service Worker 完成资源抓取）？

## Run Locally

**Prerequisites:**  Node.js

1. Install dependencies:
   `npm install`
2. Set the `GEMINI_API_KEY` in [.env.local](.env.local) to your Gemini API key
3. Run the app:
   `npm run dev`
